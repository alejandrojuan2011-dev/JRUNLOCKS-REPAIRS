# Catálogo JR Unlocks & Repairs

Catálogo web estático listo para GitHub Pages.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `assets/` y este `README.md` a la raíz.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y la carpeta `/ (root)`, luego guarda.

## Cambiar teléfono
Edita `WHATSAPP_NUMBER` en `assets/script.js` y los enlaces `wa.me` en `index.html`.

## Editar inventario
Los productos están dentro del arreglo `products` en `assets/script.js`.
